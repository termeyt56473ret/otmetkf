# Отметка — Android-приложение (с фоновой геолокацией)

Это не отдельное приложение с нуля — это твой уже готовый сайт, обёрнутый в
настоящее Android-приложение. Экраны, вход, камера, чат — всё то же самое,
просто открывается не в браузере, а как приложение с иконкой на рабочем
столе телефона. Плюс добавлена фоновая геолокация: пока приложение хотя бы
запущено (можно свернуть, экран заблокировать) — координаты продолжают
отправляться на сервер. Android потребует показывать постоянное уведомление
"Отметка активна" — это не баг, а обязательное требование системы для любого
приложения с фоновой геолокацией, без него нельзя.

## Что нужно от тебя — коротко
1. Аккаунт на GitHub (бесплатно) — если ещё нет.
2. Загрузить эту папку в свой репозиторий на GitHub.
3. Подождать 3-5 минут, пока GitHub сам соберёт `.apk`.
4. Скачать готовый файл и установить на телефон.

Дальше — подробно, по шагам.

## 1. Создай аккаунт на GitHub
Если его ещё нет: github.com → Sign up. Бесплатно, ничего платить не надо.

## 2. Создай новый репозиторий
На github.com → New repository → назови, например, `otmetka-android` →
поставь "Private" (чтобы код не был публичным) → Create repository.

## 3. Загрузи эту папку в репозиторий
На своём компьютере, в терминале (PowerShell на Windows, Terminal на Mac),
перейди в папку, которая была в скачанном архиве, и выполни по очереди:

```
git init
git add .
git commit -m "Отметка Android"
git branch -M main
git remote add origin https://github.com/ТВОЙ_ЛОГИН/otmetka-android.git
git push -u origin main
```

Если `git` не установлен — Windows попросит поставить Git for Windows
(появится ссылка на сайт при первой попытке), просто установи и повтори.

При пуше GitHub спросит логин и пароль — вместо обычного пароля нужен
Personal Access Token (GitHub больше не принимает обычные пароли для этого).
Создать его: GitHub → фото профиля → Settings → Developer settings →
Personal access tokens → Generate new token → отметь галочку "repo" →
Generate → скопируй токен и вставь его вместо пароля при пуше.

## 4. Дождись сборки
На странице репозитория на GitHub → вкладка "Actions" — там появится
запущенная сборка (жёлтый кружок = идёт, зелёная галочка = готово).
Занимает обычно 3-5 минут.

## 5. Скачай APK
Когда сборка позеленеет — кликни на неё → внизу страницы будет раздел
"Artifacts" → скачай `otmetka-debug-apk` (это zip, внутри — сам `.apk`).

## 6. Установи на телефон
Перекинь `.apk` на телефон (через USB, Telegram самому себе, Google
Диск — как угодно) → открой файл на телефоне → Android спросит разрешение
поставить из неизвестного источника (это нормально для приложений не из
Google Play) → Установить.

## Дальше — при каждом обновлении сайта
Когда я присылаю новую версию основного сайта (otmetka.zip) — на само
Android-приложение это НЕ влияет, обновлять его отдельно не нужно: оно
просто открывает твой сайт по ссылке, и там сразу всё новое.

Пересобирать APK заново нужно только если сам я пришлю обновлённую версию
именно этой папки (otmetka-android) — например если будем донастраивать
фоновую геолокацию. Тогда просто повтори `git add . && git commit -m "update" && git push`
— сборка запустится сама.

## Когда переедешь на VDS (свой сервер)
Открой файл `capacitor.config.ts`, замени в нём адрес
`https://otmetka-production.up.railway.app` на свой новый домен, сохрани,
запушь на GitHub (`git add . && git commit -m "новый домен" && git push`) —
и пересобери APK по шагам 4-6 выше.

## Если фоновая геолокация плохо работает на конкретном телефоне
На некоторых марках (особенно Xiaomi/Redmi/Huawei/Honor) система по
умолчанию агрессивно "убивает" фоновые приложения для экономии батареи.
Обычно помогает: Настройки телефона → Приложения → Отметка → Батарея →
"Без ограничений" (или "Разрешить работу в фоне") + включить автозапуск,
если есть такой пункт. На чистом Android (Pixel, Samsung в базовых
настройках) обычно всё работает без танцев с бубном.
